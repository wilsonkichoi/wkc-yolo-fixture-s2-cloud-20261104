# kv

A key-value store CLI in POSIX sh. Run `make test`.

See `kv help` for the commands.
Exit codes are listed in SPEC 1.

## Languages

`kv help` is available in English (`en`) and Spanish (`es`). It picks the language from the leading
code of `LANG` (for example `es_ES.UTF-8` gives Spanish). Any other value, or no `LANG`, gives English.
